**Yash Hospital Sales Dashboard**
A Power BI dashboard for exploring and monitoring Yash Hospital’s sales performance. It brings key sales metrics and trends together in one interactive report to support analysis and decision-making.

Dashboard overview
The dashboard can be used to:

Review overall sales performance and revenue
Track sales trends over time
Compare performance across departments and service categories
Identify top-performing products or services
Filter and explore results by date and available business segments
Tools
Microsoft Power BI
Power Query for data preparation
DAX for measures and calculations
Getting started
Clone or download this repository.
Open the .pbix dashboard file in Power BI Desktop.
If prompted, connect or update the data source.
Refresh the data to load the latest available records.
Use the report’s filters and slicers to explore the dashboard.
